# AURA - Formal AI Assistant

## Setup
1. Install Python 3.10+
2. Install Ollama from ollama.com and run: `ollama run llama3.1:8b`
3. pip install -r requirements.txt
4. streamlit run app.py

## Features V1
- 🗣️ Natural Language: Chat + Voice
- 👁️ Computer Vision: Image upload
- 🎯 Task Planning: Powered by Llama 3.1
- 🔐 Safety Layer: Formal personality
- 🛰️ Works Offline: With Ollama

Say "Hey Aura" to use voice.
